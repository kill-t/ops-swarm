# 108 - 经验版本替代与不可变追溯

## 目标与边界

可信工程师把一个已确认经验工件替换为另一个已经确认的较新工件。关系绑定两个精确 entry ID、正文版本、内容及来源 hash；不改写原候选、审核、确认正文，也不把各工件现有 version=1 改成虚构的连续正文版本。替代关系表达人工认可的后继，不表示自动归纳经验或当前根因成立。

只支持同服务、环境和 frozen/live 范围，双方必须 active/state_version=1。目标确认时间严格晚于来源，避免环且不递归扫描历史链；相同时间拒绝，选择确认时间更晚的工件后再提交。每个来源最多一个后继，每个目标最多一个前驱，支持 A→B→C；不支持分支、合并、回退或重新启用。B 后来停用或替代不改变 A→B 当时的事实，不自动恢复 A。

## 接口、身份与幂等

`POST /api/v1/experience-entries/{entry_id}/actions/replace` 始终要求可信 Bearer，仅工程师使用 manage_report。命令包含 idempotency_key、expected_entry_version、expected_entry_content_hash、expected_state_version、target_entry_id、expected_target_version、expected_target_content_hash、expected_target_state_version、reason；键和原因沿用停用的有界规范。主体与授权由系统注入，不接受自填操作者、正文或策略。

首次 201，同来源/主体/键/完整规范命令重放 200；同键异参、错误版本/hash、双方非有效状态、目标已被其他来源使用、范围不匹配或时间顺序不合法均 409，任一确认工件不存在 404。失败不预占幂等键。权限先于幂等，原成功重放只复核冻结工件、替代事实与首次可信授权，不因目标后来停用/替代而改写历史结果。

返回 applied 和不可变 replacement 事实。现有状态接口增加 replaced/state_version=2 及可选 replacement 字段，active/disabled 语义保留。停用和替代是互斥终态，已替代来源不能再停用；历史详情始终保持 confirmed 正文。状态只读取当前 entry 的直接后继，不递归跟随链或宣称找到最新可用版本。

## 持久化与并发

迁移 `0065_experience_replacement` 新增不可变 experience_replacements 与 experience_replacement_commands。替代事实保存两侧正文精确复合引用、状态版本 2、experience-replacement-v1、主体、首次授权、规范命令 hash、幂等键、原因和 UTC 时间；业务结果保存 applied/replayed/error、有限错误码与 HTTP 状态，未知目标也可留存。确认表和原停用事实不回填或改写。

应用按 UUID 升序逐行获取两侧 entry 排他锁，再复核完整工件、终态、目标前驱、范围和时间。停用仍获取单行同一锁；检索先按排名有界选出最多三条，再按 UUID 升序逐行获取共享锁，最后恢复排名返回。所有多行锁参与者使用同一顺序，避免检索按排名锁与替代按 UUID 锁形成循环等待。数据库插入保护同样锁定 entry 并校验停用/替代终态互斥，复合外键和唯一约束保护精确引用与单一前后继；原生并发写入也必须通过真实 PostgreSQL 测试。规则在纯领域层判断，触发器仅保护持久化不变量。

新事实及成功业务结果同事务保存，写后业务校验拒绝用保存点回滚事实后记录错误，数据库异常整体回滚。两张新表禁止 UPDATE/DELETE，有新事实拒绝降级，空表可降级并恢复第 107 步插入语义。

## 检索与历史兼容

经验检索升级 experience-search-v2：在原系统范围、确定性排序和最多三条之上，SQL 排除替代来源；拿到共享锁后以新语句复查停用和替代，避免等待锁后的旧子表快照。并发剔除可少于三条，不无界补查。后继也必须自己通过范围与同事故过滤，不能借替代关系绕过范围或自动回退旧经验。

当前只有即时 API 检索，没有持久化模型清单；不改历史运行策略或 checkpoint，不引入经验工具或模型上下文消费。原正文和精确版本查询保持可追溯，第 107 步的历史验收事实不改写，由本片明确新增终态及检索版本。

## 验收

纯规则验证双侧版本/hash、同键异参、状态、范围、时间顺序和前驱唯一；真实 PostgreSQL/API 验证可信主体、幂等重放、A→B→C 和 B 停用后的历史查询、两端停用竞争、相同来源/目标竞争、替代与检索两种锁顺序、业务及 SQL 故障原子性、原生终态互斥、不可变触发器、空表升降级和有事实保护。使用假调查与探针，不调用外部模型、不连接生产。
