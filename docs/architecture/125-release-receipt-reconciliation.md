# 发布演练操作的只读回执与确定性对账

## 目标与边界

在735ac2e的第124步上，补齐未来执行Worker在响应丢失后查询历史结果的只读端口。复用123已持久化的命令和状态，不新增表、执行授权、任务或业务结果。prepared请求、dispatch_eligible=false与原父运行保持；本片不派发发布、不实现Worker或恢复验证。

## 远端查询与持久事实

增加GET /__admin/simulated-release/commands/{idempotency_key}，键与原命令相同的8..100字符白名单。只在持久演练模式可用，禁用或存储不可用返回503。响应禁止缓存；查询不初始化、不创建命令、不调用PUT。存在返回200，不存在返回404，但均返回严格lab-release-receipt-v1封套：service_name、source、simulation、idempotency_key、status、command、current、effect_current。status=not_found时command=null且effect_current=false；recorded必须携带完整不可变命令。

与写入保持头行→命令锁序，读取头行FOR SHARE使目标命令、当前头和缺失结果来自同一锁定状态。重建命令结构与原始JSON摘要，并检查键、序号、前后相邻版本/修订/时间和当前状态关系；查询不扫描无界全历史，不能据此声称已检查所有中间命令。缺失邻接、损坏或错绑均503，不能降级成404。effect_current只比较版本与修订，后续同版本no-op可保持true，经历ABA则false；历史成功不因被后续命令取代而丢失。

## 有界读取与纯对账

独立异步客户端只向既有本地白名单地址GET固定路径，键严格校验；总超时至多配置10秒，响应64KiB，禁用环境代理/重定向/压缩。200/404的封套和状态必须相符，拒绝通用404、缺少来源、数字布尔、非严格时间、错误键/摘要/状态关联；失败不回退、不重试写入。

回执观测保留采集时间和精确查询路径，带时区ISO8601时间归一UTC，拒绝未来状态或命令。纯对账以调用方从124完整历史重建的cas_command、最早允许执行时间和当前时间为输入，不自行代替审批/权限核验。观测窗口30秒，逐字段比较完整CAS及摘要，命令时间不得早于允许执行时间。输出not_recorded、matched_current、matched_superseded或conflict；这些是一次有界材料的诊断，不是新执行事实或派发资格。尚未接控制面持久结果或父运行结算，后续Worker须持久化使用的回执及决定。

## 后续派发、租约与取消契约

下一片接独立执行任务前，必须固定派发截止（不晚于124准备期限和原运行期限）、尝试身份及租约代数，并在外部写入前重验当前权限、精确批准、原预算、步骤和当前CAS。读回执不能延长截止、续租、重置预算或赋予权限。not_recorded只说明查询时没有记录，不能排除尚在途的旧请求；过期/取消/失租后的旧写入必须由远端可验证期限或隔离协议阻断，不能靠本地租约推断副作用停止。

进入可能已写出的阶段后，超时/断连只能标记unknown并只读对账；历史精确匹配可确认本操作曾应用，但不能把GET当前stable作为成功证明，也不能把matched_superseded视为恢复成功。未匹配或不存在时不自动换键/重发。派发前取消可阻止写出；写出后取消不承诺撤销副作用，迟到结果不得推进已取消/失租父流程。需要另行实现持久unknown与人工收敛或远端派发约束，不能将本片查询端口描述为已完成自动恢复。

## 验收

纯契约/对账覆盖完整身份、严格字段/时间/摘要、精确CAS、缺失/冲突/历史适用性、观测边界和只读网络失败。真实PostgreSQL与实际ASGI验证缺失不写、查询重启可见、历史命令/no-op/ABA、并发快照、历史损坏失败关闭及旧接口兼容。所有测试采用隔离Testcontainers和假传输，未升级用户Compose库或连接生产。
