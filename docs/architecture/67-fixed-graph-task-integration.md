# 固定调查图接入专业任务事实

## 1. 目标与交付边界

本片把第 66 步的任务底座接到可运行的固定并行图，使专业结果在最终综合前即可查询，并验证业务提交与 checkpoint 之间的恢复边界。设计先落盘，本片已通过验收，结果见 [第 67 步进度记录](../progress/67-fixed-graph-task-integration.md)。

新增显式 `workflow_version=v2`，只接受 `multi_agent + frozen`；请求默认 `v1`，既有单 Agent、现场调查与旧 checkpoint 保持原路由。Worker 按持久版本选择图，不由模型决定。v2 仍是一个固定轮次、三个专业任务和原有综合/确定性质疑节点，不代表动态协调、完整 Harness 或上下文管理已交付。

## 2. 状态、事务与恢复

- 运行固定工作流版本。v2 checkpoint 保存版本标记，旧 checkpoint 缺标记视作 v1；跨版本恢复拒绝。运行 ID 仍生成唯一线程 ID。
- v2 协调节点原子创建轮次和日志、指标、变更任务。任务绑定冻结场景内容摘要及场景观察时间窗；这些是模拟材料，不是事故创建时的现场观测。场景内容发生变化后拒绝重放原分派。
- 每个图实例绑定本次 Worker 的运行 ID、租约及任务服务，连接、租约和运行器不写入图状态。专业节点先检查租约、业务状态和已提交结果，再申请尝试；只有新尝试允许调查。
- 专业报告和该任务实际证据保存为有界、不可覆盖的结果快照，校验角色、引用、来源、快照身份及大小；与尝试结算、任务/轮次状态和进度事件同事务提交。最终 Evidence Board 仍在父运行完成时生成，不能把阶段报告当作已综合根因。
- 恢复时已提交专业结果直接复用；业务提交前崩溃可能再次调用模型，业务提交后 checkpoint 失败不会因此重查已完成专业任务。最终提交前再次核对图中的专业报告/证据与业务快照一致。
- 父尝试失败时，未完成的专业尝试记为失败；租约接管时记为 `lease_expired`。还有父/子次数则任务回到 pending，否则 failed。父运行终止时清理所有未终结任务并结算轮次，保留已成功结果。收尾与父状态同事务，迟到子结果不能再提交。
- v2 成功必须有且仅有首轮三个完整专业结果，并与最终产物一致。checkpoint 不能成为补造缺失业务事实的依据。

## 3. 数据与接口

新增运行 `workflow_version`（默认 v1），任务分派增加可选 `evidence_snapshot_id`，新增 `agent_task_results` 与 `agent_task_events`。结果通过复合外键绑定运行、任务和成功尝试。事件使用运行内递增游标，在父任务锁内分配，避免并发事务的全局序列提交乱序造成漏读。

- 启动调查接口新增可选 `workflow_version`，非法组合返回 422；运行查询返回持久版本。
- `GET /api/v1/investigations/{run_id}/collaboration` 保持有界任务历史。
- `GET /api/v1/investigations/{run_id}/collaboration/tasks/{task_id}/result` 按需读取专业结果；任务存在但尚未提交结果返回 null，运行/任务不存在或归属不匹配返回 404。
- `GET /api/v1/investigations/{run_id}/collaboration/events` 分页读取已提交事件，支持 `after_cursor` 与 `limit`。
- `GET /api/v1/investigations/{run_id}/collaboration/events/stream` 提供独立 SSE，支持 Last-Event-ID、心跳和断线重放；旧事故时间线协议保持兼容。事件只携带身份和状态变化类型，材料通过结果接口读取。

## 4. 验收与后续

使用假模型、冻结数据及真实 PostgreSQL（业务库与 checkpoint 库分离）。验证正常 Worker 闭环、专业失败恢复、业务先提交而图失败、跨运行隔离、非法引用/角色/大小回滚、重复结算、版本拒绝、父失败与租约耗尽收尾、事件顺序/重放和迁移往返。

本片只对固定冻结查询开放 v2，不把同步现场网络调用接入新图。下一片建设最小 Harness 的调用前共享预算、尝试用量边界与受限异步取证，再推进上下文和动态调查。模型调用不保证恰好一次，现有用量记录的未知语义继续保留。

本片固定工作流版本、分派内容与冻结证据身份；完整角色/工具/提示/上下文/预算策略清单仍待 Harness 切片。后续 v2 内部图发生不兼容变化时，也必须增加明确版本或迁移策略，不能仅因同属 v2 就恢复本片 checkpoint。当前协作事件用于固定轮次的状态通知，完整交互工作台尚未接入这些新端点。
