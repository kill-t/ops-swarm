# 模型输入、Token 与估算费用预算

## 1. 本片交付与兼容

第 69 步在第 68 步次数账本上增加显式启用的 `model_budget`，只接受冻结 v2。启动时保存模型配置快照、单次输入/输出限额、运行累计 Token 和美元估算额度。未携带该配置的 v2 继续按原次数/时限策略运行，历史运行不补写预算；这不是所有运行默认启用的费用上限。

配置快照包含操作员维护的 `profile_id`、模型名、上下文窗口、结构化输出方式及输入/输出每百万 Token 美元价格。Worker 用环境配置核对完整快照；价格缺失、配置未启用或快照变化均在调用前拒绝，不能静默沿用另一模型/价格继续调查。API 不接受模型密钥或执行地址。

## 2. 输入与模型边界

把专业和综合提示的组装提取为独立职责，保留原提示内容与版本。预算模型适配器在完整消息、输出 JSON Schema 与结构化输出方式形成后预留，使用 LangChain 的结构化输出及原始消息返回能力；不新建工具循环。

首版只处理已有文本消息。输入估算使用版本化 `utf8-json-v1`：对包含全部消息、Pydantic Schema、转换后的工具 Schema 和输出方式的应用输入进行规范 JSON 序列化，按 UTF-8 字节数加固定封装余量计数。它是偏保守的估算，不是供应商精确 tokenizer；供应商隐含封装仍可能造成偏差。单次输入估算 + 输出预留 + 安全余量不得超过固定模型窗口，不通过删除提示或证据来绕过限制。

默认单次输入估算最多 24000、输出最多 4096、安全余量 1024；运行累计输入最多 200000、输出最多 24000、估算费用最多 1 美元。模型窗口和价格必须显式给定；输出限制实际传给 SDK，SDK 重试关闭。真实供应商支持情况仍需后续显式验收，预算不是硬性扣费承诺。

## 3. 持久化与失败语义

- 运行增加可空 `model_budget` JSONB；有模型预算必须是有次数预算的 v2。
- 原预留表增加可空输入快照、模型预留摘要和报告用量。新模型调用在同一个父工作项锁内校验次数、累计 Token 和费用并原子预留，专业与综合调用均绑定原身份；工具调用不携带这些字段。
- 输入快照以大小上限保存完整应用输入，摘要保留散列、估算版本、提示版本、输入估算、输出上限和预留费用。列表仅返回摘要；按运行和调用 ID 单独读取快照。快照不包含密钥、租约或 Worker 连接配置。
- 用字典 Schema 保留原始消息，再执行 Pydantic 校验；已取得原始响应的解析失败仍保存完整报告用量。核对供应商 `token_usage` 的字段和值，不能把兼容层补的零当成真实用量；缺字段或 null 保持未知，非法负值/类型/总和显式失败。未取得响应、取消或父失联也保持 null。实际费用只按固定价格和完整报告用量估算。
- 次数、Token 和费用预留均不返还。已报告用量超过预留时按较大值计算占用，保留超支事实并停止；少用不能清零重试额度。未知请求保留全部占用。并发中的既有请求可能已经发生，不能抹掉其费用。
- 复用第 68 步租约、超时、父收尾与迟到拒绝。幂等重放必须核对同一输入摘要；费用或 Token 耗尽、窗口越界及模型配置冲突均终止自动重试。

## 4. 接口与验收

启动请求及运行响应增加可选 `model_budget`。原预算 GET 增加模型配置与占用汇总，区分已报告、未知和保守占用；新增按调用读取模型输入快照的只读接口。沿用既有错误格式，不提供修改预算或价格的写接口。

输入端点为 `GET /api/v1/investigations/{run_id}/calls/{call_id}/model-input`：运行或调用不存在、跨运行读取返回 404；已存在但未保存模型输入的工具/历史调用返回 null。预算列表不加载输入快照。`reported_input_tokens` 与 `reported_output_tokens` 是已报告部分的合计，存在未知调用时 `reported_cost_usd` 为 null，不能把部分合计当成完整消耗。

应用输入上限为 256 KiB，数据库 JSONB 另设 512 KiB 防线；预留和用量摘要分别限制 8 KiB。单次输入配置最大 262144，输出最大 32768；累计输入最大一千万、累计输出最大一百万、费用上限配置最大 100 美元。安全余量限制 128～8192，模型窗口限制 1024～2000000。费用使用 Decimal 并向上取整到百万分之一美元，避免小额请求被舍入为零。降级发现已有模型预算时拒绝删除审计事实。

Worker 需显式配置 `LLM_BUDGET_PROFILE_ID`、`LLM_CONTEXT_WINDOW_TOKENS` 和已有的模型输入/输出单价；价格支持 `LLM_*_COST_PER_MILLION_USD`，也兼容 `EVALUATION_*_COST_PER_MILLION_USD`。启动请求的 `model_budget.profile` 必须与 Worker 配置一致。模型、端点或计价策略改变时由操作员更新配置版本标识；不把供应商模型别名视为权重版本证明。预算模型显式设置单次返回数量为 1，拒绝兼容层静默替换结构化输出方式。

使用真实 PostgreSQL 验证并发最后额度、输入与次数原子预留、重试累计、未知用量、超支、租约失联及迁移；使用假模型和 SDK HTTP 假传输覆盖三个结构化输出方式、长输入提前拒绝、输出参数传递、解析失败记账、专业与综合全路径、配置改变拒绝和历史兼容。没有真实模型调用。

后续独立切片再建设受限异步现场取证、ContextBuilder 的材料筛选/摘要与完整版本清单。本片输入快照不等于已完成上下文管理或长期记忆。
