# v3 第三轮综合与开放假设恢复

## 目标与边界

第 97 步已经完成第 3 轮专业任务，并保存任务证据、专业结果和工作摘要。本片只综合这些第三轮业务事实，生成一份绑定第三轮协调计划的 `pending_review` 开放假设，使最大调查轮次的材料进入后续独立审查前的明确业务状态。

第三轮综合不读取 checkpoint 自报材料，不重新执行专业任务，也不混入前两轮摘要、假设、审查或路由。模型仍只提出自由文本假设、置信度、支持证据、反证与未解问题；系统注入待审查状态。本片不执行第三轮独立审查或停止路由，不进入 LangGraph 人工暂停、候选结论、规划、处置或父运行结算。

## 按轮调用与上下文

三轮综合继续使用根级 `synthesize` 操作，并以业务轮次固定调用槽位：第 1、2、3 轮分别使用 `invocation_index=0、1、2`。槽位进入持久幂等键和预算账本；新父租约不能清零预算，也不能让前两轮成功调用冒充第三轮来源。

第三轮使用独立提示 `third-round-open-hypothesis-synthesis-v1` 和角色版本 `dynamic-third-round-synthesis-v1`。上下文服务按槽位 2 选择第 3 轮协调计划，从业务库重建完整任务集合，并复核每项任务已经成功且存在匹配的证据、结果和工作摘要。材料清单只记录第 3 轮事故背景、任务分派、证据和工作摘要；输出证据引用只能来自这些材料。

模型成功调用、上下文清单和开放假设均保留不可变来源。存在同槽位多个成功调用、其他材料的成功调用、错误轮次计划、任务集合漂移、证据闭包越界或租约失效时拒绝推进。

图 v12 已存在第三轮任务完成终态 checkpoint，因此固定为历史第三轮执行图。新运行发布图 v13，在第三轮专业分支汇合后增加综合节点：

图 v1～v12 保留各自拓扑、状态和恢复语义。图 v13 的 checkpoint metadata 与 state 同时固定 `workflow_version=v3`、`graph_version=dynamic-investigation-graph-v13`，不能用 v13 图恢复 v12 checkpoint。

## 持久化与恢复

复用 `investigation_open_hypotheses`、调用账本和上下文清单，不新增业务表、字段或公开 API。现有开放假设表按运行和轮次唯一，可在同一运行保存三条按业务轮次排序的记录；第三轮记录绑定第三轮计划、当前父尝试和槽位 2 的成功综合调用，前两轮记录保持不可变。

模型调用成功但开放假设尚未提交时，新父租约按槽位 2 和完整上下文复用成功调用，不再次请求模型。开放假设已提交但节点 checkpoint 尚未写入时，恢复从业务库复核并返回原记录，不新增调用或假设。业务数据库与 checkpoint 仍不组成跨库事务，恢复依赖不可变调用、按轮唯一事实和最终来源重建。

共享模型次数、时限、Token 与估算费用继续累计。默认调用次数预算最多允许三轮各一个专业任务的路径完成第三轮综合；更多专业任务必须在运行创建时显式扩大预算，不能为第三轮静默追加额度。

## 迁移与兼容

迁移 `0055_third_round_synthesis` 只把 `investigation_runs.graph_version` 约束扩展到图 v13。存在图 v13 运行，或存在根级 `synthesize` 槽位 2 及以后调用事实时，拒绝降级到 `0054_third_round_investigation`；调用预留是 v12“只执行第三轮任务”边界之后最早的不可变行为事实，失败或未知调用也不能通过改写运行图版本隐藏。

允许降级时恢复图 v1～v12 约束。旧图 checkpoint、前两轮开放假设和综合调用、v1/v2 工作流不回填、不改写。用户 Compose 业务数据库不在本切片自动升级。

## 验收标准

- 第二轮 `follow_up` 路径在第三轮任务全部完成后只向槽位 2 综合发送第 3 轮任务、工作摘要和完整证据，并保存绑定第三轮计划的开放假设。
- 三条开放假设按业务轮次稳定查询；前两轮事实保持不变，第三轮假设状态为 `pending_review`，父运行保持 `running`。
- 第二轮 `await_human`、`candidate_evaluation` 及首轮终止路径不产生第三轮综合调用或假设。
- 覆盖模型成功后事实提交前、事实提交后 checkpoint 前两个恢复窗口，证明模型、来源、预算和假设不会重复。
- 图 v12 仍只执行第三轮任务；图 v13 与旧 checkpoint 隔离。
- 图 v13 运行和槽位 2 综合调用分别触发降级保护；唯一 Alembic head 为 `0055_third_round_synthesis`。
