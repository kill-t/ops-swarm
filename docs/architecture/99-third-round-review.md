# v3 第三轮开放假设独立审查与恢复

## 1. 目标与边界

第 98 步已经把第 3 轮专业材料综合为绑定第三轮计划的 `pending_review` 开放假设。本片只让独立审查读取该假设及其综合调用的同源第三轮材料，保存一份绑定第 3 轮假设的 `recorded` 审查事实，使最大调查轮次具备可恢复的支持、反证、证据缺口和竞争性解释。

审查模型只提出结构化意见与有限建议方向，不决定最大轮次后的业务路由，不创建第 4 轮任务，也不进入 LangGraph 人工暂停、候选结论、规划、处置或父运行结算。审查通过仍不表示根因已被客观证明，不授予执行资格。

## 2. 调用身份与上下文隔离

三轮独立审查继续使用根级 `review` 操作，并以业务轮次固定调用槽位：第 1、2、3 轮分别使用 `invocation_index=0、1、2`。第三轮另用提示 `third-round-open-hypothesis-review-v1` 和角色版本 `independent-third-round-review-v1`；槽位、提示和角色同时进入持久调用、上下文清单和预算复核。

第三轮上下文服务按槽位 2 选择第 3 轮协调计划、开放假设及其槽位 2 综合来源，从业务库重建工作摘要和完整证据。审查材料必须与第三轮综合清单逐项同源，只在末尾追加当前开放假设；不得混入前两轮假设、审查、路由或 checkpoint 自报材料。输出证据引用只能来自第三轮材料闭包。

图 v1～v13 保留各自拓扑和恢复语义。图 v14 的 checkpoint state 与 metadata 同时固定 `workflow_version=v3`、`graph_version=dynamic-investigation-graph-v14`；v14 不恢复 v13 checkpoint。

## 4. 持久化、幂等与恢复

复用 `investigation_hypothesis_reviews`、开放假设、调用账本和上下文清单，不新增业务表、字段或公开 API。审查表已经按开放假设唯一，同一运行可保存三份按业务轮次查询的不可变记录；第三轮记录绑定当前父尝试、第三轮假设和槽位 2 成功审查调用。

恢复仍覆盖两个提交窗口：

1. 模型调用成功但审查事实尚未提交时，新父租约重建相同第三轮输入和清单，复用槽位 2 成功响应后提交事实，不重复模型请求或预算预留。
2. 审查事实已提交但 checkpoint 尚未写入时，新父租约直接读取并校验业务事实，不重复模型、来源访问、预算或写入。

同一运行、同一审查槽位存在多条成功调用时，查询和恢复入口必须拒绝歧义。共享次数、时限、Token 与估算费用继续累计，第三轮审查不得在执行途中追加或重置额度。完整三轮路径需要 13 次模型调用，超过既有默认上限 12；调用方必须在创建运行时显式固定至少 13 次的调用预算，系统不为新图静默放宽既有默认策略。

## 5. 迁移与降级

迁移 `0056_third_round_review` 把运行图约束扩展到 v14，并把根级审查合法槽位扩展为 `0、1、2`。存在图 v14、槽位 2 及以后审查调用，或第 3 轮及以后审查事实时拒绝降级到 `0055_third_round_synthesis`；失败和未知调用也是已经发生的行为事实，不能通过改写图版本隐藏。

允许降级时恢复图 v1～v13 和审查槽位 `0、1` 约束。旧 checkpoint、前两轮审查、v1/v2 工作流不回填、不改写。用户 Compose 业务数据库不在本切片自动升级。

## 6. 验收标准

- 第二轮 `follow_up` 路径完成第三轮综合后，只用第三轮同源材料和假设执行槽位 2 审查，保存绑定第 3 轮假设的 `recorded` 事实。
- 完整三轮验收运行在创建时显式固定 13 次模型调用预算；默认上限 12 保持不变，并会在第三轮审查前确定性停止。
- 三份审查按轮次稳定查询；前两轮事实保持不变，父运行继续为 `running`。
- 第二轮 `await_human`、`candidate_evaluation` 及更早终止路径不产生第三轮审查调用或事实。
- 第三轮模型成功后事实提交前、事实提交后 checkpoint 前均可跨父租约恢复，且不重复模型、来源、预算或事实。
- 第三轮审查上下文与第三轮综合清单逐项同源，错误轮次、错误假设、越界证据和同槽位多成功调用均被拒绝。
- 图 v13 仍只综合第三轮；图 v14 与旧 checkpoint 隔离。
- 图 v14、槽位 2 审查调用和第三轮审查事实分别受到降级保护；唯一 Alembic head 为 `0056_third_round_review`。

## 7. 面试表达

> 第三轮已经到冻结策略允许的最大调查轮次，但独立审查仍必须与前两轮一样可追溯。我把业务轮次映射到持久审查槽位，第三轮使用独立提示和角色版本，并要求审查清单与生成该假设的综合清单逐项同源。模型调用与审查事实分开落库，所以两个崩溃窗口都能幂等恢复；本切片只形成审查事实，最大轮次后进入人工还是候选路径继续由下一片确定性代码决定。
