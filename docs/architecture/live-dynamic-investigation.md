# 现场动态协作与版本化来源

2026-11-05。承接本地版本的首项核心行为。组件验收与现场演示边界见[实现记录](../progress/live-dynamic-investigation.md)。

## 目标与边界

新建现场v3运行实际进行动态专业分工、受限MCP取证、多轮综合与独立审查，并在终端事务保存交接、释放Worker。复用现有LangGraph及任务/预算/上下文服务，不新增调度框架，不让现场模式读取冻结样本。人工交接后的重评、候选及处置兼容仍属下一项完整行为。

旧v1/v2及冻结v3 graph-v15保持原契约。新现场运行固定`dynamic-investigation-graph-v16`、`task-evidence-live-dynamic-mcp-v1`和UTC观测截止；共享`summary-context-v1`、原协调策略和预算规则。图拓扑不重写，按实例绑定来源与恢复版本；v15/v16 checkpoint不得互相恢复。运行模式、版本和截止创建后不可改变。

## 精确现场窗口与专业权限

系统将运行服务、观测截止及稳定快照身份注入任务，协调模型只选择角色、目标和有界回看长度。新现场策略要求所有回看秒数为正的完整分钟，日志/指标至多15分钟，变更至多6小时；在任务入库前校验，提示输入同时说明此限制。旧冻结策略的秒级窗口规则不改。

现场截止使用创建时刻向下取整到秒。新图允许与事故起点处于同一秒的截止，保持原始微秒时间与精确观测窗口的各自语义。

现场图依据已持久TaskAssignment的精确窗口调用日志/指标MCP及本地变更适配器；不把61秒向上取整成120秒，不扩大任务授权。MCP维持原工具及Schema，来源服务、窗口、类型、内容大小与证据引用继续复核。同步取证经现有受限线程执行器，不在异步图内阻塞网络；超时、来源失败显式结束尝试，不回退直连或冻结材料。

## 持久化、上下文与恢复

复用运行、轮次、专业任务、尝试、证据快照、账本、上下文清单、摘要、假设、审查及终端交接表。新0097迁移定点增加现场版本组合和动态现场窗口约束，旧策略分支不变；禁止有新运行事实时降级。

首次协调仍可显式启用`coordination-experience-v1`，现场仅选择同模式、同范围有效确认经验；选择与首次预留同事务冻结。空选择及历史版本引用同样持久，不把经验当当前证据或审批。协调清单保存实际现场取证策略；所有角色、补查及重试继续累计原调用、输入输出、估算费用和总期限，unknown不清零。

同任务已保存证据重用原快照；重试保留任务身份、新建尝试。计划与任务窗口、成功调用、报告证据和工作摘要必须同源。恢复核对持久版本、checkpoint metadata及业务工件，租约失效或来源损坏不推进。终端交接仍要求最高完成轮次、无未完成任务/预留、精确路由及有效父租约，不把调查终端当动作授权。

## 必要验证

使用脚本模型，不调用外部模型。纯规则覆盖新旧策略组合、整分钟/范围拒绝及来源隔离；MCP/线程边界使用固定响应验证精确请求、失败不回退和已有线程容量规则。真实PG验证创建时冻结、原生约束、经验冻结及终端事务；代表性图场景执行实际专业任务、至少一轮补查与独立审查，并验证checkpoint恢复不重取已提交材料。协议集成的假上游不得描述为Compose现场演示。

验证直接创建新现场运行，使用独立临时 PostgreSQL 与 checkpoint 库。验收入口和结果见进度记录。
