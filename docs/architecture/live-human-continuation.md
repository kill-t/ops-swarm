# 现场人工续接与单步骤恢复

graph-v16 的终端交接进入现有可信人工等待和候选链。可信工程师补充事实或约束，独立准备任务封存当时的审查材料与人工事件前缀，重评 Worker 消费该输入。审查工件保留原图版本，人工陈述仍与已核实的取证记录分开。重评及候选评估继续使用原运行预算和时限。

可评估的重评结果由候选接口消费。仍有人工约束或预算阻断时保留等待和原因；重评提出的补查意图也保留为人工可读的交接记录，本片由工程师接管这一方向。

原生准入接受 v15 冻结和 v16 现场两种明确的版本组合。沿用原有交接、人工版本、可信身份、租约和内容哈希绑定。v16 可取消或进入原候选收尾状态，终态仍需要对应业务事实。降级遇到已消费的现场人工或候选来源时拒绝回退，保留审计事实。

本片验收目标为从 v16 现场来源开始，经可信人工补充和实际重评形成单步骤回滚候选，完成条件核验、审批、幂等执行及客观恢复验证，再收敛事故。集成测试使用真实 PostgreSQL、脚本模型和受控本地演练接口。真实 Compose 现场演示与失败再调查分别按[本地版本交付设计](local-multi-agent-release-scope.md)验收。
