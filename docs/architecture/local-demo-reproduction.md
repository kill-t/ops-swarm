# 本地脚本演示与可复现验收入口

本入口整理已有隔离演练步骤，不增加业务 Agent 能力或发布前置。使用独立 Compose 项目 `opsswarm-local-demo`、独立命名卷和当前发布装配；已有发布项目及历史数据不迁移、不改写。共享本机端口，因此运行前须确认其他栈未占用。

演示配置由仓库脚本生成，不依赖旧案例、缓存脚本或已有令牌。四类可信角色使用独立随机凭据，原始令牌与环境文件仅保存在忽略的本地演示目录；模型固定为容器网络中的脚本端点，不请求外部模型。工具调用响应引用输入中的证据身份，明确作为工程链演示，不宣传为真实模型推理或实际计费用量。

提供人工交接、正常恢复、未恢复后一次回流三条流程。流程通过现有 HTTP API 提交真实可信命令、等待常驻 Worker，核对执行幂等、业务样本、事故状态、槽位及原预算。只读 GET 可以有界等待；写请求不在网络结果不明时自动重发。每个案例保存独立结构化报告和持久对象身份，失败保持原业务事实。

未恢复场景临时停止本演示项目的恢复采样 Worker，在回滚被客观确认后注入连接池故障，再恢复采样；新窗口另登记配置变更，核对原期限、旧账本与持久人工接管。恢复 Worker 在失败路径也会尝试恢复。脚本不直接写业务数据库，不调用任意 Shell 或修改运行时实现。

案例写入前先检查健康、角色与容器 UTC 连续性；存在倒退、明显跳变或依赖不可用时返回环境阻塞报告，不能把缺失观测当作成功，不修补系统时钟或放宽业务窗口。此入口的组件验收与完整 Compose 场景结果分别记录；既有发布欠项不会因脚本存在而自动变为已通过。
