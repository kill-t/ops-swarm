# 最小可信协作台

事故详情复用当前控制面的操作者凭据与业务 API。凭据仅驻留当前页面会话的内存。身份、角色、权限和有效期由服务端身份接口确认。可信模式的 SSE 使用带授权头的请求和已接收事件游标重连，刷新后由服务端持久事实重建页面。

控制面使用 `bearer` 模式时，在浏览器输入已配置的 `credential_id.secret`。工程师、审批者和执行者按各自身份操作。凭据配置与生成规则见[可信操作者身份](104-trusted-operator-identity.md)。

现场调查通过 `GET /api/v1/incidents/{incident_id}/collaboration-navigation` 提供只读导航，定位当前等待版本、准备、重评和候选任务。协作台以服务端返回的版本、摘要和权限构建显式人工命令，连接异常时保留同一命令及幂等键供重试。权限提示只用于交互，所有写入沿用控制面的授权审计和业务守卫。

协作台展示调查、预算、证据、处置、恢复和回流交接。条件核验逐条填写，审批显式确认依据。执行者提交准备后，页面直接用准备响应中的版本、摘要和时限生成独立派发确认。失败、过期或冲突时提示刷新最新事实。

后台任务可通过刷新按钮重新读取。事故事件触发自动更新。页面刷新后重新验证身份并定位已有业务事实，短窗口执行以服务端时间和批准依据为准。
