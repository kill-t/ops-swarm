# 可信协作台的状态更新与人工续接

历史浏览器走查记录到人工补充返回 201 后准备按钮等待超时，重开页面可以继续。日志只记录了提交结果和超时，具体触发原因仍待复验。组件回归复现了提交后的读请求丢失同期事故事件，以及后台准备就绪但页面停留在旧状态的问题。修复前新增的三项组件回归均失败。[原浏览器记录](local-release-entry.md)

提交期间合并状态更新，成功后沿用现有接口重读持久事实。准备、重评、候选、执行、采样、收敛及回流等待由服务端返回状态识别。观察到等待后，间隔两秒补读，在六十秒窗口内发起请求。失败、终态和窗口截止结束自动补读。事故或身份切换与组件卸载取消旧请求。同一调查中，完整命令相同才保留输入，版本或摘要变化需要重新选择。短执行窗口内仍可直接使用准备响应，派发需要单独确认。[协作台设计](../architecture/trusted-collaboration-workroom.md)
