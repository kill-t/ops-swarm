# 产品 Harness 恢复对照与阶段计时

2026-11-06。复用产品现场 v3 集成用例，保留原无经验基线，新增同经验配置的正常与中断对照，并采集阶段耗时及调用计数。

真实 PostgreSQL 17.11 上三个用例通过。第二轮审查成功记录落库后中断，恢复复用原调用与证据，预算快照一致，仅提交一次终端交接。原生库使用非 UTC 会话时来源核验报冲突，最小探针复现了同一时刻的偏移字符串差异。以 UTC 会话复验通过。详见[验收报告](../../evaluations/harness-recovery.md)。

面试可说明，恢复策略以持久记录为依据，并用故障注入核对请求、业务记录和预算三层事实。进一步优化前先重复采样第二轮审查，区分来源复核和数据库开销。
