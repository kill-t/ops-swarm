# 历史装配去重与项目入口收口

本批一起完成历史依赖核对、代码去重、文档与验证。十四代旧图只有历史工厂和恢复回归引用，默认 Worker 不领取；但[旧设计](../architecture/100-third-round-terminal-routing.md)明确保留各自拓扑与 checkpoint 恢复语义，因此不直接退役。真正删除的是重复的装配实现，边界见[现场协作设计](../architecture/live-dynamic-investigation.md)。

历史工厂由 1,870 行缩至 699 行，共用冻结来源、运行和模型准入，以及按需阶段构造。公开工厂仍显式绑定原图与版本，当前 v15/v16 导出保持。一次装配共享预算运行器，不跨调用或新租约复用，也不提前创建未使用阶段。图节点、checkpoint、持久查询、迁移和业务规则未修改。

首页从 948 行收口为 86 行，只呈现当前能力、验收缺口、启动与代码入口；保留的手工命令及历史接口转至[参考页](../manual-reference.md)，修正相对链接，删除首页重复的阶段流水与架构清单。Docker 构建排除用户输出目录，未读取、删除 `output/` 或 `tmp/`。AGENTS 同步整批交付偏好。

十四个版本的真实图构造与原版快照逐项对照，公开签名、图接线、依赖身份及各类拒绝结果共 238 组一致。新增及受影响单元检查共 66 项通过，覆盖版本边界、旧拓扑前沿、预算共享、按需创建和新租约隔离；关键入口为 `tests/unit/investigation/test_legacy_dynamic_factories.py` 与 `test_dynamic_factory.py`。Ruff、Mypy 和差异检查通过，文档链接及保留命令核对通过。旧图集成文件只核对可收集，未执行数据库恢复链；服务保持关闭，无模型或工具请求。详细对照脚本、原版快照及日志留在忽略缓存。

本批完成的是装配和项目入口整改，不代表完整发布验收完成。下一步围绕完整演示与复现收拢正式入口，避免依赖忽略目录里的临时脚本；正常收敛仍需稳定环境补验，141 原欠项保持。面试时可说明如何依据恢复承诺划定保留边界，并以原版对照证明删除重复实现没有改变执行资格与预算语义。
