## 决定

当前版本收口为“可演示、可恢复的多 Agent 本地事故处置版本”。核心能力先于页面扩展：现场动态专业协作、独立审查、受限MCP、上下文和共享预算、可信经验、人工实际续接、单步骤安全处置及一次失败再调查。详细有限清单、现状证据、场景、依赖及延期统一见[交付范围](../architecture/local-multi-agent-release-scope.md)。

成功以客观恢复、事故收敛和复盘结束；失败以实际再调查/独立复查后的持久接管或明确停止收束。通用多步骤和回流后再次自动执行延期，不再按142顺延；不支持的意图仍须有明确出口。最后接最小可信协作台、部署、重启及执行幂等演示，全部必需项通过后发布即结束。
