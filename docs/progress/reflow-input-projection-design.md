# 回流模型输入投影设计

四阶段[基线](reflow-remediation-baseline.md)显示压缩协调输入后仍有后续超限风险。冻结案例中，原候选来源的旧模型输入占 13,074 字节，人工路由占 8,083 字节，且旧模型业务消息里的证据和假设与候选来源字段完全一致。综合又通过分派记录携带准入账本。

本次确定[四阶段投影策略](../architecture/live-reinvestigation-handoff.md#有界模型输入策略)。完整来源继续为守卫及审计提供重建依据，模型输入按阶段挑选必要事实，策略随运行固定。用只读案例检查字段结构及重复关系，检查设计链接和 Git 差异。运行时投影、增量迁移、双端一致性及 Compose 验收仍待实施。

面试可用两个摘要解释设计：来源摘要绑定完整审计事实，输入摘要绑定一次实际分配的模型请求。两个摘要各自可重算，改变投影时旧运行继续按旧策略重建。
